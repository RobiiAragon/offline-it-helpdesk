# Onboarding and Offboarding

## Onboarding (hiring manager)

- Submit the **New Hire** form in the IT portal at least **5 business days** before the start date.
- Include role, department, manager, start date, required software and shared mailboxes.
- Laptops are prepared in advance and handed over on day one at the Service Desk counter in Building B, 8:30-10:00.
- The new employee receives a temporary password by SMS on the start date and must enroll in MFA during the first sign-in.

## Role changes

Access is role-based. When someone changes department, the manager submits a **Role Change**
request so old access is removed and new access is granted. Access is not copied from a
colleague ("make me like Juan").

## Offboarding

- HR triggers offboarding automatically from the termination date.
- Accounts are disabled at **18:00 on the last working day**.
- Email is retained for 90 days; the manager can request delegate access or an auto-reply.
- Laptops, badges, security keys and phones must be returned to the Service Desk. Unreturned equipment is reported to HR.
- OneDrive files are transferred to the manager after 30 days if requested.
