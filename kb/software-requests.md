# Software Installation and Licenses

## Approved software

Approved applications are installed without a ticket:
- **Windows:** Software Center (Start menu → Software Center).
- **macOS:** Self Service app.

Examples: Microsoft 365 apps, Teams, Zoom, Adobe Acrobat Reader, 7-Zip, Python, Visual
Studio Code, Git, Notepad++, PaperCut Print Deploy, GlobalProtect.

## Requesting new software

1. Open the IT portal → **Request something → Software**.
2. Provide the product name, vendor, version, business reason and number of users.
3. New software goes through a security review (typically **5 business days**) and, if paid, a license purchase approved by your cost-center manager.
4. Once approved, the package is added to Software Center for everyone who needs it.

## Paid licenses

Licenses for Adobe Creative Cloud, AutoCAD, MATLAB, SolidWorks and Visio are assigned
individually. Unused licenses (no sign-in for 90 days) are reclaimed automatically and you
are notified by email first.

## Not allowed

Peer-to-peer file sharing, cracked software, browser extensions that are not in the
approved list, and personal cloud sync clients (e.g. personal Dropbox) on company devices.
