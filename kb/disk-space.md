# Low Disk Space and Slow Computer

## Freeing disk space (Windows)

1. Run **Disk Cleanup** as administrator via Software Center → "Disk Cleanup (Admin)".
2. Empty the Recycle Bin and clear `Downloads`.
3. Set OneDrive to **Files On-Demand**: right-click the OneDrive cloud icon → Settings → **Free up space**. Files stay in the cloud and download when opened.
4. Uninstall unused apps from Settings → Apps.
5. Check large folders with the **WinDirStat** tool from Software Center.

Keep at least **15% free space**; Windows updates fail below roughly 10 GB free.

## Freeing disk space (macOS)

Apple menu → About This Mac → More Info → **Storage Settings**. "Store in iCloud" is
disabled on company Macs; use OneDrive Files On-Demand instead.

## Slow computer checklist

- Restart at least once a week. A "fast startup" shutdown is not a restart.
- Check Task Manager (Ctrl+Shift+Esc) for processes using high CPU or memory.
- Close browser tabs; each tab can use hundreds of MB of memory.
- Make sure Windows Update and Software Center show no pending restarts.
- If the laptop is older than its refresh cycle, request a replacement (see "New Laptop Setup and Replacement").
